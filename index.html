How to read these numbers

Page loads = the gift site was opened. Interactions = clicks on buttons and cards. Visits = distinct anonymous browser-tab sessions. A visit is not a person: a new tab or cleared storage starts a new one. A click shows something was opened, not that it was read, watched, or listened to.

    About session IDs

    When the gift site opens, the browser makes a random ID and keeps it for that tab only. Events with the same ID are grouped as one visit. It contains no name or location, so it can’t identify who was using the site.
